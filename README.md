# 小龟过四级

> 碎片时间背单词的安卓小工具：你本来就在刷手机，那就顺手记一个词。

「小龟过四级」是一个装在你自己手机上的背单词小工具。当你在刷短视频、刷社交软件的时候，
它按你设定的间隔（比如每 5 分钟）在屏幕上浮一张单词卡，你点「记住了」或「还不认识」就行。
不需要专门坐下来打开学习 App，碎片时间就顺手过了一遍。

## 特性

- **四本词书**：真题核心词（513）、阅读难词（671）、高频词汇（559）、乱序全库（4434），共 5090 词，可多选
- **悬浮提醒**：进入你勾选的应用才计时，到点弹卡片，离开即停
- **科学复习**：每个词至少出现 3 次；连续 3 次「记住了」才算掌握，中途忘了重新计数
- **状态追踪**：待攻克 / 待巩固 / 已掌握 / 我的生词，一目了然
- **本地存储**：进度、打卡记录都在本机，不上传任何服务器
- **可爱小龟**：整套界面以小龟为主题，边背边被治愈

## 使用说明

1. 安装 APK（首次需允许「安装未知来源应用」）
2. 依次开启必要权限：通知、使用情况访问、忽略电池优化（前 3 项必开）；悬浮窗、精确闹钟、无障碍为可选
3. 在「设置 → 监控应用」勾选你平时会刷的应用
4. 在「设置 → 复习词书」选择要背的词书
5. 打开首页开关，然后正常用手机

## 环境与构建

- Android SDK 34，minSdk 24
- 语言：Java，无第三方运行时依赖（仅 AndroidX + Material）
- 构建：`sh build.sh assembleDebug`，产物在 `app/build/outputs/apk/debug/`
